# RAINWATCH AI — Frontend

This folder contains the complete React + TypeScript frontend for the RAINWATCH AI SIH 2026 prototype.

## Stack

- React 18
- TypeScript
- Vite
- React Router
- Tailwind CSS
- Recharts
- Lucide React

## Run

```bash
npm install
npm run dev
```

The main source is inside `src/`.

### Main folders

```text
src/
├── components/   # Reusable UI components
├── data/          # Prototype/demo data
├── pages/         # Application pages
├── services/      # Service/API layer
├── types/         # TypeScript definitions
├── App.tsx
├── index.css
└── main.tsx
```

The frontend includes dashboard, rainfall, risk assessment, forecast, history, risk map, alerts, dataset, model, architecture and about views.
